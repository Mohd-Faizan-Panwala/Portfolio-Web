## 💻 Tech Stack
* **Frontend:** React.js, Tailwind CSS, Vite
* **Backend:** Node.js, Express.js *(in development)*
* **Tools:** Git, GitHub, VS Code, EmailJS (Zero-DB contact form)
* **Deployment:** Vercel (CI/CD)

## ⚙️ Features
* **Matrix/Terminal Typewriter Effect:** Custom React hooks simulating terminal execution on load.
* **Component-Driven Architecture:** Clean, reusable React components for the UI.
* **Database-Free Contact Flow:** Secure, real-time message forwarding using EmailJS.
* **Fully Responsive:** Tailored layout for mobile, tablet, and desktop environments.
